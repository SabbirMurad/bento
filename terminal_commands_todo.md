1. show <widget name> - sets that widget as show in the settings e. g. show clock turns on the clock if it is not already on
2. hide <widget name> - sets that widget as hidden in the settings e. g. hide clock turns off the clock if it is not already off

3. bg lists - shows the list of background that are available
4. bg set <id/name> - sets the background
5. bg upload - opens file picker so can upload new video to set the background
